## I. Introduction - l'histoire de la pensée économique
<u>Il existe différents courants :</u> 
- Le courant libéral
- le courant keynésien
- le courant marxiste
- Les courants classiques et néoclassiques
Chaque courant a interprêté le comportement des agents économiques d'une manière différente : 
- Certains privilégient le marche et favorisent l'économie de marché
- D'autres privilégient l'économie de l'état
3 Questions se posent : 
-Comment l'éco pdt elle et répartit elle les richesses ?
-Le marché peut il se réguler seul / s'auto réguler ?
-Quel est le rôle de l'état ?
### 1. Le courant libéral
Def = économie du marché "libre" (détenir les ressources + faire des investussements) => propriété privée des facteurs de prod
éco marché diff éco état: pas d'équilibre du marché, l'état n'intervient pas pour réguler

### 2. Le courant marxiste
Def = l'état détient les facteurs  de prod (opposé du CL) => économie de l'état -> propriété collective

### 3. Le courant keynésien
Def = libéralisme avec l'intervention de l'état
